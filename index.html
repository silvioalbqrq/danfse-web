DANFSe a partir do XML

Arraste os XMLs de NFS-e e receba o DANFSe em PDF — gerado no seu navegador pelo mesmo componente oficial da Receita, sem enviar nada para a internet.

Abra pelo servidor local. O navegador bloqueia o motor WASM em file://. Use o iniciar-site.bat ou rode python -m http.server 8020 na pasta do site.
